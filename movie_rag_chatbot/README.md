# Movie RAG Chatbot

스포일러 수위를 조절할 수 있는 영화 정보 검색 및 추천 챗봇 (RAG 기반)

## 기획 배경

평소 쉴 때 영화를 틀어놓고 취미 생활이나 집안일을 하는 것을 좋아한다.
그런데 영화에 온전히 집중하지 못하다 보니, 중간중간 보면 내용이 이해되지 않아서 처음으로 돌아가 영화를 다시 보거나 아예 꺼버리는 일이 잦았다.
그래서 좋아하는 장르를 골라 검색하고, 줄거리를 미리 파악한 뒤, 편하게 감상할 수 있는 도구가 있으면 좋겠다고 생각했다.

처음에는 특정 장르 데이터만 다루려 했지만 데이터 양이 너무 적어서 전체 장르 검색으로 확장했다.

개인적인 용도를 넘어서도 쓸모가 있다고 생각한다.
요즘 스마트 TV는 음성으로 AI에게 원하는 것을 요청할 수 있는데, "영화 추천해줘"라고 하면 대개 평점/인기 상위 영화만 보여준다. 그 대신 사용자의 요청(장르/분위기/소재)에 맞춰 필터링해 추천하는 챗봇이 있으면 더 유용하겠다고 생각했다.

다만, 줄거리를 미리 알고 보는 것을 좋아하는 사람도 있지만 스포일러를 싫어하는 사람도 있기 때문에 스포일러 수위를 사용자가 조절할 수 있도록 했다.
그래서 기본적으로 스포일러 없이 알려주고, 결말과 줄거리를 명시적으로 요청하면 상세 내용까지 제공하도록 했다.

## 프로젝트 구성

**공통**
- `config.py`: 경로, API 키 설정
- `collect_data.py`: TMDB, 위키백과에서 영화 데이터 수집 -> movies.jsonl
- `build_index.py`: 데이터를 청킹 및 임베딩해 ChromaDB에 저장

**바닐라 RAG**
- `rag.py`: 검색(제목 인식 + 스포일러 필터), 답변 생성
- `app.py`: 챗봇 실행

**LangChain 적용**
- `rag_langchain.py`: LangChain 기반 검색, 답변
- `app_langchain.py`: 챗봇 실행

## 실행 방법
1. 가상환경: `python3 -m venv .venv && source .venv/bin/activate`
2. 설치: `pip install -r requirements.txt`
3. API 설정: `.env` 생성 후 TMDB_TOKEN, GEMINI_API_KEY 입력
4. 데이터 수집: `python collect_data.py` (movies.jsonl이 이미 있다면 생략)
5. 인덱스 생성: `python build_index.py`
6. 챗봇 실행:
    - 바닐라 RAG: `python app.py`
    - LangChain: `python app_langchain.py`

## 트러블슈팅
### 1. [데이터] 위키백과 줄거리 수집량 부족
- **문제**: `wikipedia` 라이브러리로 줄거리를 수집했더니 줄거리 양이 너무 적었다(169/500). 그 결과, "우주를 배경으로 한 SF 영화"를 검색해도 SF 장르 영화가 추천되지 않았다.
- **원인**: 대부분의 영화가 짧은 소개(overview)만 있었는데, overview는 홍보성 문구 위주라 "SF"같은 장르나 내용 키워드가 거의 없어서 의미 검색이 잘 되지 않았다. 또, `wikipedia` 라이브러리 자체가 오래돼서 응답이 불안정했다.
- **해결**: 라이브러리 대신 위키백과 공식 API를 직접 호출하는 방식으로 변경했다. `extracts`로 본문을 받아서 `== Plot ==` 부분만 잘라냈다.

### 2. [데이터] 위키백과 공식 API로 바꿨는데도 줄거리가 27개만 수집됨
- **문제**: 수정 후에 오히려 수집된 줄거리가 27개로 줄었다.
- **원인**: 응답 상태코드가 429(Too Many Requests)로, 요청을 너무 빠르게 많이 보내서 위키백과가 차단했다.
- **해결**: 429가 오면 `time.sleep(5)` 이후 최대 3번까지 재시도하고, 요청 간격도 0.5초로 늘렸다.
- **결과**: 248/500 줄거리 수집 성공. 유실 방지를 위해 `movies.jsonl`에 저장했다.

### 3. [검색] 특정 영화(예: 인셉션)를 검색하지 못함
- **문제**: "우주를 배경으로 한 SF 영화 추천"은 답을 잘 하지만, "인셉션 줄거리 알려줘"에는 데이터에 인셉션이 있음에도 불구하고 "정보가 없다"고 답했다.
- **원인**: 질문 문장 전체("인셉션 줄거리 결말까지")로 의미 검색을 해서 "줄거리, 결말" 같은 일반 단어에 밀려서 "인셉션"이라는 제목이 상위에 잡히지 않았다. 제목 기반 검색을 만들지 않아서 발생한 문제였다.
- **해결**: 제목 기반 검색을 추가했다. 질문에 등록된 영화 제목이 포함되면 그 제목으로 메타데이터 필터링(`where`)해서 해당 작품조각을 우선 검색한다.

### 4. [응답] 답변이 중간에 잘림
- **원인**: `max_tokens=1000` 제한 때문에 긴 줄거리 답변이 중간에 끊겼다.
- **해결**: `max_tokens=2000`으로 상향했다.

### 5. [환경] 구글로 마이그레이션
- Python 3.9 -> 3.11 업그레이드, 최신 `google-genai` 라이브러리로 전환
- 임베딩 및 답변 생성 모두 Gemini로 전환 후 검색 품질 개선 확인
