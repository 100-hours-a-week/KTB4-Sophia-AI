## 회고
이번 과제는 교재와 공식 문서, 구글 검색을 통해 미니 퀘스트를 직접 풀어나가보았다. 강사님께서 최대한 문서와 교재만 참고해보라고 하셔서 AI에게 코드를 요청하기보다는 내가 작성한 코드가 맞는지 확인하거나 오류가 발생했을 때 어떤 부분이 문제인지 파악하는 용도로만 활용했다.
전체적으로 양이 많아서 시간이 걸리기도 했고, 할 일을 몰아서 하는 성격 때문에 이번주 후반이 시간이 빠듯하기도 했지만, 데이터 시각화의 코드 실행 결과가 그래프로 바로 눈에 보이니 다른 과제보다 흥미롭게 느껴졌다. 이번 주는 무난하게 마무리할 수 있었던 한 주였던 것 같다.
